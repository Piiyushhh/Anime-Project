# 🌀 ANIME Project

## 🎯 Overview
**ANIME** is an anime discovery web app built using a **MERN-based stack** (MongoDB, Express.js, React.js, Node.js) with **Tailwind CSS** for styling.  
It uses the **JIKEN API** to fetch anime data and allows users to explore, search, and manage their watchlist.

> ⚠️ This is a **learning project** — not a production-ready app. It’s currently private and updated regularly as part of my full-stack learning journey.

---

## 🧩 Features
- 🔍 **Search Functionality** — Search and explore anime using the JIKEN API.  
- 📜 **Anime Info Pages** — Displays anime details such as title, synopsis, and type.  
- 🎥 **Trailer Section** — Implemented but currently non-functional (API lacks trailer URLs).  
- 📺 **Watchlist** — Add or remove anime from your personal watchlist (local state only).  
- ⚡ **Responsive UI** — Designed using Tailwind CSS for a smooth modern experience.
